You opened the interface file directly. It needs the application behind it.

Here is how to start it properly

This page is only the screen. The part that stores your data and does the calculations has to be started first, by the launcher.

1
Extract the ZIP file first.
Right-click EOSB_System.zip and choose Extract All…, then pick Documents or Desktop. Do not open the ZIP by double-clicking it and work inside — Windows only pretends that is a folder, and nothing you save there is kept.
2
Open the extracted EOSB_System folder.
3
Double-click START HERE.bat (or EOSB.bat).
A small black window opens and stays open — leave it alone. Your browser opens the application by itself, at an address starting with http://127.0.0.1
How to tell you are in the right place: the address bar must start with http://127.0.0.1 — not with file:///. If it starts with file:///, the application is not running.

If the launcher opens and closes immediately, or you see an error, double-click DIAGNOSE.bat in the same folder. It writes diagnostic_report.txt explaining exactly what went wrong.
